Pada lab ini, Anda akan belajar perintah-perintah dasar Linux Console yang biasa digunakan dalam mengelola server. Ikuti langkah-langkah di bawah dengan teliti.

  • Memahami navigasi direktori (pwd, cd, ls).
  • Mengelola file dan folder (mkdir, touch).
  • Mengecek identitas user (whoami).
Progress Lab 1 dari 4 Selesai
1. Cek Identitas User ▼
Ketik whoami di dalam terminal untuk melihat user apa yang sedang Anda gunakan saat ini.
2. Lihat Posisi Direktori ▼
Ketik pwd untuk melihat letak direktori Anda, dilanjutkan dengan ls -l.
3. Buat Folder Baru ▼
Ketik perintah mkdir tugas_server.
4. Verifikasi Akhir ▼
Pastikan folder berhasil dibuat, lalu klik tombol "Tandai Selesai" di bawah.
